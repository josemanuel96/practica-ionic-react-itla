## Descripción del Proyecto

Esta aplicación fue desarrollada utilizando **Ionic Framework** y **React** como parte de la asignatura **Desarrollo de Aplicaciones Móviles**.

La aplicación implementa un menú de navegación y varias funcionalidades solicitadas en la práctica.

## Tecnologías Utilizadas

* Ionic Framework
* React
* TypeScript
* HTML
* CSS
* JavaScript
* Capacitor
* Android Studio

## Funcionalidades

### Página Inicial

Muestra los datos personales del estudiante:

* Fotografía tipo 2x2
* Nombre completo
* Matrícula
* Correo electrónico

### Sumadora

Permite ingresar dos números y obtener su suma.

### Traductor de Números a Letras

Convierte números del 1 al 1000 a su representación en letras en español sin utilizar APIs externas.

### Tabla de Multiplicar

Genera la tabla de multiplicar de un número hasta el 13.

### Experiencia Personal

Muestra un video de YouTube donde se explica la experiencia durante el desarrollo de la práctica.

## Instalación

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Entrar al proyecto:

```bash
cd practica-ionic
```

3. Instalar dependencias:

```bash
npm install
```

4. Ejecutar la aplicación:

```bash
ionic serve
```

## Compilación para Android

```bash
ionic build
npx cap sync android
npx cap open android
```
